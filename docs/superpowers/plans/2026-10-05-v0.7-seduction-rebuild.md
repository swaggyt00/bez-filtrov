# v0.7 Seduction Rebuild Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v0.7 with the approved 480-card authored deck, two-player Afterdark support, randomized temporary-effect durations, and the Seduction visual redesign.

**Architecture:** Keep the existing React/Vite app and role-aware deck engine. Extend the card schema only with participant-count and duration metadata, centralize final text rendering in the deck layer, replace the authored corpus in the existing data-file layout, and restyle the existing screens rather than adding new product surfaces.

**Tech Stack:** React, TypeScript, Vite, CSS, existing `tsx` assert/audit scripts, GitHub Actions/Pages.

**Spec:** `docs/superpowers/specs/2026-10-05-v0.7-seduction-rebuild-design.md`

## Global Constraints

- Exactly 480 authored cards: 20 cards in every scenario × heat × type bucket.
- Approved card style: short spoken Russian, one clear idea, no pseudo-psychology, no unexplained referents, and every persistent Dare states when it ends.
- `couple` and `sex` retain current release player rules; `party` remains 3–6; `afterdark` becomes 2–6.
- Afterdark cards requiring 3+ players must never be selected in a two-player session.
- Duration outcomes are exactly `1 круг`, `2 круга`, `3 круга`, `до конца игры`; Light never returns `до конца игры`, and Hard keeps the permanent outcome less likely than finite outcomes.
- Runtime never generates card prose; all card wording is authored ahead of time.
- Seduction visual direction: near-black, deep crimson, warm off-white, restrained glow/motion, mobile-first, card-first, no fake navigation/features.
- No analytics, accounts, backend, leaderboards, AI-generated runtime cards, or new standalone game modes in this release.

## Review Focus

- Two-player Afterdark must still have valid Truth and Dare choices at every heat, including after role/target filtering.
- A card with `minPlayers: 3` must never leak into a two-player Afterdark session.
- `{{duration}}` must always resolve before a card reaches the UI or persistence layer.
- Random duration selection must obey the allowed set for each heat, including boundary random values near 0 and 1.
- Saved/resumed games must keep the already-rendered card text and must not reroll duration after reload.
