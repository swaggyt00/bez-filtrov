# v0.8 Competitor-Grounded Content Rebuild Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the v0.7 480-card deck with a 1,440-card competitor-grounded authored deck, eliminate perspective bugs, and gate release with deterministic content/data tests plus Playwright E2E instead of TinyFish.

**Architecture:** Keep the current React/Vite game shell and selection engine. Add lightweight provenance metadata and a public-source registry, split the larger authored corpus into scenario/heat modules, strengthen the existing data audit/tests, then add Playwright smoke tests to CI. No runtime content generation or unrelated UI redesign.

**Tech Stack:** React, TypeScript, Vite, tsx-based data tests/audits, Playwright, GitHub Actions, GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-10-05-v0.8-competitor-content-rebuild-design.md`

## Global Constraints

- Exact deck size: 1,440 authored cards.
- Exact bucket counts: Couple 60 Truth + 60 Dare per heat; Sex Light 60+60, Hot 70+70, Hard 80+80; Party 50+50 per heat; Afterdark 60+60 per heat.
- Every v0.8 card must be traceable to an approved public competitor source or public competitor pattern.
- Do not bulk-copy protected competitor wording verbatim; preserve the useful mechanic/pattern and rewrite final Russian copy for this app.
- Current player is always the Truth answerer and Dare actor.
- Opponent-voice first person (`я`, `меня`, `мне`, `мой/моя/моё/мои`) is forbidden unless it is explicitly quoted speech spoken by the current player.
- Existing scenario flow, Seduction visual system, persistence, duration mechanics, skip/re-roll behavior, target eligibility, gender semantics, pairing rules, and Afterdark 2–6 behavior remain intact.
- No runtime AI generation.
- TinyFish is not part of v0.8 QA.
- Release gate: content audit, deck/data tests, Playwright E2E, production build, final bucket/source coverage report.

## Review Focus

- Perspective ambiguity: a card shown to one player must never read as if the opponent is speaking unless quoted speech explicitly says so.
- Target resolution: cards requiring another player must render that player unambiguously and must not leave `{{...}}` placeholders.
- Corpus padding: higher counts must not come from cosmetic variants of the same core idea or one repeated interaction family.
- Two-player Afterdark: every heat/type bucket must retain a healthy eligible pool after `minPlayers` filtering.
- Persistence/randomness: a rendered target/duration string must remain byte-for-byte stable after resume rather than rerendering.
