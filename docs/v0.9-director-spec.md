# «Без фильтров» v0.9 — Director foundation

v0.9 replaces the global Light/Hot/Hard choice with a hidden-session Director.

## Core loop

Mode → current player → choose 🔥 / 🔥🔥 / 🔥🔥🔥 → Director reveals Truth or Dare → resolve card → persist effects → logical continuation → occasional Event → eventual «Без фильтров» culmination.

## Two independent axes

- **Risk** is chosen every turn. It controls how dangerous/awkward/intense the next beat may be.
- **Session Stage** is hidden. It controls what is physically/narratively possible right now.

A three-fire choice never jumps stages.

## Director state

The Director tracks session stage, tension, current chain, chain depth, position, leader, per-player clothing, active effects, risk history, caution pressure, boundaries and recent history.

Skip and hard boundaries never increase caution pressure.

## Sex start

Default clothing state is **clothed**. Optional starts: underwear or nude. Clothing is tracked per player and gates later physical stages.

## Migration

The old 1,440-card v0.8 catalog stays intact while v0.9 is introduced. A temporary adapter maps legacy cards into the new Director model. Cards can then be curated with explicit v0.9 metadata without a destructive all-at-once rewrite.
