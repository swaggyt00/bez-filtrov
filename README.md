# Без Фильтров — Правда или действие 18+

Мобильная 18+ игра для 2–6 совершеннолетних игроков. **v0.4** — большой контентный перезапуск: только три понятных уровня, крупные колоды, защита от повторов тем и отдельный Sex-сценарий, который действительно построен вокруг секса, а не бесконечной прелюдии.

Играть: **https://swaggyt00.github.io/bez-filtrov/**

> Только для совершеннолетних. Любую карту можно заменить или пропустить без объяснений. Алко-карты опциональны и технически отделены от сексуальных действий.

## Как устроена игра

1. Вводишь имена игроков.
2. Для каждого выбираешь М / Ж — это используется в грамматике карточек.
3. Выбираешь сценарий.
4. Выбираешь один из трёх уровней: **Легко / Горячо / Жёстко**.
5. Играешь: **Правда** или **Действие**.

Никакой шкалы 1–10, разогрева, adaptive offset, Boss Round, Extreme/Madness или анкеты на пол-экрана.

## Сценарии

- **Пара** — отношения, ревность, бывшие, сексуальная совместимость и неудобная правда.
- **Секс** — прямой сексуальный режим: позы, мастурбация, оральные предпочтения, роли, контроль, фантазии и переход к реальному сексу по взаимному желанию.
- **Компания** — 3–6 игроков: выбор людей, флирт, поцелуи, приватные челленджи и социальные провокации.
- **После полуночи** — ночной хаос, риск, приватные задания и отдельные опциональные алко-карты.

## Три уровня

- **Легко** — флирт, неловкость и первые действия.
- **Горячо** — больше тела, меньше намёков.
- **Жёстко** — самые прямые вопросы и действия конкретного сценария.

Выбранный уровень — точная колода. Игра не подмешивает более мягкие уровни.

### Sex / Жёстко

Это отдельная большая колода: **140 Truth + 140 Dare**.

Dare распределены по 35 тематическим действиям и 9 механикам. Среди тем есть выбор сексуальной позы, наездница, позы сзади и лицом к лицу, мастурбация и взаимная мастурбация, прямое предложение перейти к сексу, оральные предпочтения, раздевание, зеркало, душ, ролевые сценарии, смена инициативы и контроль.

Ключевое правило:

- **Truth = отвечаешь.**
- **Dare = реально что-то делаешь или принимаешь конкретное решение о действии.**

## Защита от повторов

Каждая карточка имеет внутренние `theme` и `mechanic`.

При выдаче движок:

- не повторяет использованный ID, пока конкретная колода не закончилась;
- старается не выдавать тему, которая встречалась среди последних 8 карточек;
- старается не повторять механику последних 3 карточек;
- при исчерпании перемешивает только выбранный тип карточек, а не всю игру.

Поэтому несколько разных формулировок одной идеи не должны идти подряд.

## Русский язык и пол игроков

Поддерживаются:

- мужские и женские формы;
- склонение русских имён по падежам;
- случайный второй игрок для карточек, где он нужен;
- сохранение пола в настройках и сессии.

Форматы вроде `встретил(-а)` не используются. Аудит дополнительно рендерит всю базу в мужской и женской версиях и ловит сломанные шаблоны.

## Алкоголь

Алко-карты можно полностью отключить. В них используются только небольшие глотки любого напитка, включая безалкогольный.

Автоматический аудит запрещает:

- опасные drinking-челленджи;
- несколько шотов / «до дна» / «на скорость»;
- любую карточку, которая одновременно является алкогольной и сексуальным действием.

## Сохранение

Текущая игра автоматически хранится в `localStorage`. Сохраняются игроки, пол, сценарий, уровень, использованные карточки, текущий ход и уже открытая карточка.

Настройки v0.3 автоматически мигрируют: старые `Extreme` и `Madness` превращаются в `Жёстко`. Старые незавершённые v0.3-сессии не продолжаются, потому что ID колоды полностью изменены.

## Аудит

```bash
npm run audit:cards
```

Проверяется:

- ровно **2220** карточек и точный размер каждой колоды;
- уникальность ID и отсутствие дублей внутри одного сценария;
- разнообразие тем и механик;
- мужские/женские формы после реального рендера;
- отсутствие `(-а)`;
- отсутствие опасных алкогольных заданий;
- отсутствие связки `alcohol + sexualAction`;
- для `Sex / Жёстко` — количество прямых сексуальных Dare, разнообразие тем и механик;
- чрезмерная текстовая похожесть разных тем.

Полная проверка:

```bash
npm run check
```
