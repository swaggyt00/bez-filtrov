# Без Фильтров — Правда или действие 18+

Мобильная 18+ игра для совершеннолетних игроков. **v0.6** — переработка движка и контента: карточки теперь учитывают пол и роль игрока до выдачи, повторы считаются по смыслу, а четыре сценария имеют разную драматургию и разную эскалацию.

Основной сайт: **https://swaggyt00.github.io/bez-filtrov/**

> Только для совершеннолетних. Любую карту можно заменить или пропустить без объяснений.

## Концепция v0.6

- **Пара** — узнать друг друга лучше. Смешное, личное, отношения, ревность, бывшие, поцелуи и неудобная правда. Перчинка растёт с уровнем, но прямого разврата нет.
- **Секс** — единственный сценарий с прямыми сексуальными действиями. Легко создаёт контакт, Горячо держит состояние «ну вот, почти», Жёстко запускает короткие откровенные мини-сцены с понятным возвратом в игру.
- **Компания** — 3–6 игроков. Выбор людей, реакции всей группы, подколы, флирт, смешные задания, признания и алкоголь как часть обычной колоды.
- **После полуночи** — 3–6 игроков. Алкогольный ночной трэш: абсурд, стыд, одежда, переодевания и смелые телесные задания. Даже на Жёстко это не превращается в сценарий «Секс».

## Уровни

Названия одинаковые, но смысл зависит от сценария:

- **Легко** — безопасный вход в характер выбранного режима.
- **Горячо** — заметная эскалация, больше личного/телесного/неловкого.
- **Жёстко** — максимальная версия именно этого сценария, а не та же карточка с более грубыми словами.

Для `Секс`:

- Легко — взгляд, массаж, шея, ухо, близость и лёгкие прикосновения;
- Горячо — частичное раздевание, сильное напряжение, больше тела и контроля, но без прямого запуска секса;
- Жёстко — позы, мастурбация, оральные ласки, контроль, наблюдение, игрушки и ролевые мини-сцены.

## Ролевая модель карточки

Карточка хранит не только готовый текст, но и смысловые признаки:

- `actorGenders` / `targetGenders` — кому карточка вообще может выпасть;
- `actorRole` / `targetRole` — кто ведёт, получает действие, выбирает или наблюдает;
- `coreIdea` — основная идея карточки для контроля смысловых повторов;
- `interaction` — тип переживания: юмор, признание, флирт, физический контакт, контроль, roleplay и т.д.;
- `pairing` — нужна ли обычная пара игроков или взаимно допустимое близкое взаимодействие;
- `scene.endCondition` — где заканчивается мини-сцена и игра возвращается к следующему ходу.

Текст не собирается из `тема × шаблон`. Каждая карточка хранится как законченная авторская фраза.

## Гендер и подбор пары

В текущем релизе:

- **Пара** и **Секс** — ровно два игрока, мужчина + женщина;
- **Компания** и **После полуночи** — 3–6 игроков;
- в групповых режимах у каждого игрока есть настройка **«Интимные задания: со всеми / с мужчинами / с женщинами / ни с кем»**.

Движок сначала проверяет пол и допустимых партнёров, а уже потом выбирает карточку. Поэтому женская роль не должна выпадать мужчине и наоборот.

## Sex / Hard: карточка должна оставаться игрой

Главное правило v0.6: жёсткая карточка не заканчивается фразой «идите заниматься сексом».

Сексуальные Dare строятся как короткие управляемые сцены:

`HOOK → ROLES → OBJECTIVE → ESCALATION → END`

У сцены есть конкретная ситуация, роли или правило, одна основная механика и точка завершения. После неё игроки возвращаются к следующей карточке.

Примеры механик: допрос, незнакомцы в отеле, смена контроля, повязка, ограничение движений с быстрым освобождением, выбор позы, зеркало, наблюдение, взаимная мастурбация, игрушка на один раунд, импровизированный roleplay.

## Алкоголь

Отдельного переключателя больше нет.

- в **Паре** и **Сексе** алкогольных карточек нет;
- в **Компании** алкоголь встроен в обычную тусовочную колоду;
- в **После полуночи** алкоголь — заметная часть концепции.

Алкогольные задания используют только небольшие глотки и не объединяются с прямыми сексуальными действиями.

## Редакторские правила

- Truth должен раскрывать желание, признание, историю, конфликт, выбор, ценность или совместимость.
- Dare должен требовать действия; если достаточно просто произнести ответ, это скорее Truth.
- Нельзя использовать бессмысленные конструкции вроде `в теме X`, `если говорить про X`, `идеальный сценарий на тему X`.
- Нельзя оставлять потерянные ссылки вроде `попробовать это`, когда на карточке не названо, что именно.
- Разные формулировки одной идеи не считаются настоящим разнообразием.
- Прямые сексуальные действия разрешены только в `Секс / Жёстко`.
- `Секс / Легко` и `Секс / Горячо` строят возбуждение через контакт и напряжение, а не через команду заняться сексом.

## Защита от повторов

При выдаче движок:

1. фильтрует сценарий, уровень и Truth/Dare;
2. проверяет пол текущего игрока;
3. проверяет наличие допустимого второго игрока;
4. исключает уже использованные карты, пока колода не закончилась;
5. старается не повторять недавний `coreIdea`;
6. старается менять `interaction`;
7. только после этого случайно выбирает карточку и допустимую цель.

## Проверки

Тест движка:

```bash
npm run test:deck
```

Редакторский аудит:

```bash
npm run audit:cards
```

Аудит проверяет структуру карточек, `coreIdea`, `interaction`, гендерные ограничения, потерянный контекст, запрещённый ИИ-канцелярит, смысловые повторы, алкоголь, изоляцию прямого секса в Sex/Hard и наличие точки возврата у сексуальных мини-сцен.

Полная проверка:

```bash
npm run check
```

## Сохранение

Текущая игра и настройки хранятся в `localStorage` под ключами v6. Настройки старых версий мигрируют; незавершённая игра старой версии не подхватывается после замены модели колоды.
