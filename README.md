# Без Фильтров — Правда или действие 18+

Мобильная 18+ игра для 2–6 совершеннолетних игроков. Версия **v0.3** — полный перезапуск ядра: меньше настроек, меньше «умной» шелухи, сильнее разница между Правдой и Действием, а выбранная жёсткость работает сразу.

Играть: **https://swaggyt00.github.io/bez-filtrov/**

> Только для совершеннолетних. Любую карту можно заменить или пропустить без объяснений. Алко-карты опциональны и не связаны с согласием на сексуальные действия.

## Как устроена игра

1. Вводишь имена игроков.
2. Для каждого выбираешь М / Ж — это используется в грамматике карточек.
3. Выбираешь сценарий.
4. Выбираешь один из пяти уровней жёсткости.
5. Играешь: **Правда** или **Действие**.

Никакой шкалы 1–10, разогрева, adaptive offset, Boss Round или анкеты на пол-экрана.

## Сценарии

- **Пара** — отношения, ревность, желания и физическая близость.
- **Секс** — action-first режим: на высоких уровнях действия действительно телесные.
- **Компания** — выбор людей, флирт, неловкость и провокации.
- **После полуночи** — более грязный и хаотичный формат с опциональными алко-картами.

## Жёсткость

- **Легко** — флирт и лёгкая неловкость.
- **Горячо** — телеснее и прямее.
- **Жёстко** — неудобные признания и реальные действия.
- **Экстрим** — сразу тяжёлые карты, без подмешивания более мягких уровней.
- **Безумие** — самые рискованные социальные и физические челленджи колоды.

Выбранный уровень — это **точный слой колоды**. Если выбрано «Экстрим», карточки «Легко» или «Горячо» не выпадают.

## Карточки v0.3

Активная база содержит **200 заново написанных карточек**:

- 4 сценария;
- 5 уровней;
- на каждой комбинации ровно 5 Truth + 5 Dare;
- всего 100 Truth + 100 Dare.

Количество специально уменьшено относительно старой v0.2: сейчас приоритет — качество ядра, а не большая цифра в README.

Ключевое правило базы:

- **Truth = отвечаешь.**
- **Dare = реально что-то делаешь.**

На уровнях `Extreme` и `Madness` автоматический аудит отдельно проверяет, что Dare остаются действиями, а Sex на верхних уровнях не превращается в разговорник.

## Русский язык и пол игроков

Карточки поддерживают:

- мужские и женские формы;
- склонение имён по падежам;
- выбор случайного другого игрока в карточке;
- сохранение пола вместе с игровой сессией.

В базе не используются конструкции вида `встретил(-а)`.

## Сохранение

Текущая игра автоматически хранится в `localStorage`. Сохраняются:

- игроки и их пол;
- сценарий и уровень;
- использованные карты;
- текущий игрок;
- даже уже открытая карточка и выбранный для неё второй игрок.

Ответы игроков приложение не записывает.

## Аудит

```bash
npm run audit:cards
```

Проверяется баланс матрицы сценарий × уровень × Truth/Dare, дубли, качество верхних Dare, взрослые Truth, опасные drinking-челленджи и нежелательные гендерные форматы.

Полная проверка:

```bash
npm run check
```

## Локальный запуск

Node.js 22+:

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```
