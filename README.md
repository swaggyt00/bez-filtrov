# Без Фильтров — Правда или действие 18+

Мобильная 18+ party-game на React + TypeScript для 2–6 совершеннолетних игроков. Игра не привязана к конкретным именам: игроки вводят их перед началом сессии. Встроено 500 карточек, умная выдача, игровые пресеты, границы, адаптивная интенсивность, специальные раунды и пользовательские карточки.

> **18+ only.** Игра рассчитана только на совершеннолетних участников. Любое действие — только по взаимному согласию. Пропуск всегда доступен. Алкогольная механика не требует алкоголь: можно использовать воду или любой безалкогольный напиток.

## Возможности

- 2–6 игроков с любыми именами.
- 500 встроенных карточек: 250 «Правда» + 250 «Действие».
- 10 уровней интенсивности.
- Игровые пресеты: «Классика», «Для пары», «Каверзно», «Интим», «Про отношения», «Вечеринка».
- Плавный разогрев или старт сразу с выбранной сложности.
- Адаптация сложности по реакции игроков: «Слабо / Норм / Жёстко».
- Hard/soft limits для чувствительных тем.
- Умная выдача с защитой от повторов тем, механик и похожих формулировок.
- Память поведения текущей сессии без записи личных ответов игроков.
- Карточки-продолжения по ранее выпавшим темам.
- Расширенные механики: выбор, шкала, угадывание, одновременные ответы, топ-3, совместные задания.
- Duo Round каждые 6 ходов и Boss Round каждые 10 ходов.
- Опциональное правило «ответь / выполни или один небольшой глоток» с безалкогольной альтернативой.
- Собственные карточки с уровнем, категориями и типом отношений.
- Игра на 20 / 40 / 60 ходов или без лимита.
- До 12 локальных сохранённых сессий.
- Звук и вибрация на поддерживаемых устройствах с возможностью отключения.
- Локальное хранение данных в браузере, без аккаунта и сервера.

## База карточек

Встроенная база содержит ровно 500 карточек:

- 250 «Правда»;
- 250 «Действие»;
- по 25 карточек каждого типа на каждом уровне 1–10.

Пользовательские карточки добавляются поверх встроенной базы и участвуют в том же алгоритме выдачи.

## Аудит базы

```bash
npm run audit:cards
```

Аудит проверяет количество и баланс карточек, уникальность ID и текста, категории, форматы отношений, чрезмерную похожесть формулировок, разнообразие механик, покрытие высоких уровней и потенциально опасные алкогольные задания.

Полная локальная проверка:

```bash
npm run check
```

## Локальный запуск

Требуется Node.js 22+.

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## GitHub Pages

Проект заранее настроен для GitHub Pages через GitHub Actions. Vite использует относительный `base`, поэтому репозиторий можно назвать как угодно.

После загрузки репозитория:

1. Открой **Settings → Pages**.
2. В **Build and deployment → Source** выбери **GitHub Actions**.
3. Workflow `.github/workflows/deploy-pages.yml` автоматически проверит базу, соберёт приложение и опубликует `dist`.
4. Последующие push в `main` будут автоматически обновлять сайт.

## Хранение данных и приватность

Сессии, пользовательские карточки и настройки хранятся только в `localStorage` текущего браузера. Приложение не отправляет личные ответы игроков на сервер и в текущей версии вообще не имеет backend/API.
