# Без Фильтров — Правда или действие 18+

Мобильная 18+ игра для совершеннолетних игроков. **v0.8** — большой контентный rebuild: 1440 карточек, жёсткая проверка перспективы игрока, provenance для публичных референсных банков и детерминированный browser QA через Playwright. Визуальная оболочка Seduction из v0.7 сохранена.

Основной сайт: **https://swaggyt00.github.io/bez-filtrov/**

> Любую карту можно заменить или пропустить без объяснений.

## Режимы

- **Пара** — ровно два игрока, мужчина + женщина. Юмор, привычки, воспоминания, ревность, границы, конфликты и уязвимость.
- **Секс** — ровно два игрока, мужчина + женщина. Легко строит напряжение, Горячо становится телеснее и откровеннее, Жёстко включает короткие сексуальные сцены с понятной точкой окончания.
- **Компания** — 3–6 игроков. Подколы, выборы, реакции группы, флирт и социальная неловкость.
- **После полуночи** — 2–6 игроков. Ночной трэш, алкоголь, одежда, флирт, неловкость и временные правила.

Каждая v0.8-карта хранит `sourceRef` на публичную референсную семью. Референсы используются для механики, темпа и паттернов; карточки адаптированы под нашу структуру, русский язык и правила адресации.

Главное правило перспективы: **Truth всегда однозначно отвечает текущий игрок; Dare всегда является командой текущему игроку от лица игры.** Если нужен второй участник, он задаётся через target/имя, а не через невидимое «я / меня / мне».

## Роли и подбор игроков

Карточки могут хранить:

- `actorGenders` / `targetGenders` — кому подходит роль;
- `pairing` — нужна ли взаимно допустимая близкая пара;
- `minPlayers` — минимальное число участников для конкретной карты;
- `coreIdea` — смысл карты для защиты от повторов;
- `interaction` — тип взаимодействия;
- `scene.endCondition` — точку возврата в игру у Sex/Hard сцен;
- `sourceRef` — provenance публичного референсного банка.

В групповых режимах у каждого игрока есть настройка близких заданий: `со всеми / с мужчинами / с женщинами / ни с кем`.

## Временные эффекты

Карты с временным правилом используют семантический `{{duration}}`, который разрешается один раз при показе карты.

Возможные значения:

- `1 круг`;
- `2 круга`;
- `3 круга`;
- `до конца игры`.

Вероятности зависят от накала. Уже показанный текст сохраняется как готовая строка, поэтому после перезагрузки длительность не меняется.

## Визуал

Сохраняется Seduction-система v0.7: почти чёрный фон, глубокий красный акцент, тёплый светлый текст и card-first мобильная композиция. Анимации отключаются через `prefers-reduced-motion`.

## Проверки

```bash
npm run test:deck
npm run audit:cards
npx playwright install chromium
npm run test:e2e
```

`audit:cards` проверяет 1440 карточек, размеры bucket-ов, дубли, `sourceRef`, перспективу, metadata, запрещённые формулировки, `minPlayers`, duration-плейсхолдеры, двухигроковый Afterdark и границы Sex/Hard.

Playwright детерминированно проверяет старт режимов, Party 2→3 players validation, Afterdark для двух игроков, mobile overflow и сохранение уже разрешённого `{{duration}}` после reload/resume. TinyFish в релизном QA v0.8 не используется.

Pull request должен пройти deck tests, editorial audit и Playwright E2E. GitHub Pages публикуется только после push в `main`.
