# Без Фильтров — Правда или действие 18+

Мобильная 18+ игра для совершеннолетних игроков. **v0.7** пересобирает контент и визуал: новая авторская колода на 480 карточек, `После полуночи` теперь работает от двух игроков, временные эффекты получают случайную длительность, а интерфейс переведён в чёрно-красный Seduction-стиль.

Основной сайт: **https://swaggyt00.github.io/bez-filtrov/**

> Любую карту можно заменить или пропустить без объяснений.

## Режимы

- **Пара** — ровно два игрока, мужчина + женщина. Юмор, привычки, воспоминания, ревность, границы, конфликты и уязвимость. Прямых Sex-действий нет.
- **Секс** — ровно два игрока, мужчина + женщина. Легко строит напряжение, Горячо становится телеснее и откровеннее, Жёстко включает короткие сексуальные сцены с понятной точкой окончания.
- **Компания** — 3–6 игроков. Подколы, выборы, реакции группы, флирт, социальная неловкость и алкоголь.
- **После полуночи** — 2–6 игроков. Ночной трэш, алкоголь, одежда, флирт, неловкость и временные правила. Прямые сексуальные действия остаются только в режиме `Секс`.

## Колода v0.7

Всего **480 карточек**:

- 4 сценария;
- 3 уровня: `Легко`, `Горячо`, `Жёстко`;
- `Правда` и `Действие`;
- ровно **20 карточек в каждом сценарий × уровень × тип bucket**.

Редакторский стандарт: короткий разговорный русский, одна понятная идея на карту, без псевдопсихологии, ИИ-канцелярита и потерянных ссылок вроде «сделай это», когда непонятно что именно.

Для `Действия` должно быть ясно, что конкретно сделать, с кем или чем и когда действие заканчивается.

## Роли и подбор игроков

Карточки могут хранить:

- `actorGenders` / `targetGenders` — кому подходит роль;
- `pairing` — нужна ли взаимно допустимая близкая пара;
- `minPlayers` — минимальное число участников для конкретной карты;
- `coreIdea` — смысл карты для защиты от повторов;
- `interaction` — тип взаимодействия;
- `scene.endCondition` — точку возврата в игру у Sex/Hard сцен.

В групповых режимах у каждого игрока есть настройка близких заданий: `со всеми / с мужчинами / с женщинами / ни с кем`.

## Временные эффекты

Карты с временным правилом используют семантический `{{duration}}`, который разрешается один раз при показе карты.

Возможные значения:

- `1 круг`;
- `2 круга`;
- `3 круга`;
- `до конца игры`.

Вероятности зависят от накала: на `Легко` постоянный эффект не выпадает, на `Жёстко` он возможен, но остаётся реже конечных вариантов. Уже показанный текст сохраняется как готовая строка, поэтому после перезагрузки длительность не меняется.

## Визуал v0.7 — Seduction

Интерфейс построен вокруг почти чёрного фона, глубокого красного акцента, тёплого светлого текста и сдержанного свечения. Карточка — главный объект игрового экрана. Нет фальшивых вкладок, статистики или декоративных функций, которых не существует.

Анимации короткие и отключаются через `prefers-reduced-motion`.

## Проверки

```bash
npm run test:deck
npm run audit:cards
npm run build
```

`audit:cards` проверяет точное количество карточек, bucket-размеры, дубли, обязательные metadata, запрещённые формулировки, `minPlayers`, duration-плейсхолдеры, двухигроковый Afterdark и границы Sex/Hard.

Pull request прогоняет deck tests, редакционный audit и production build. GitHub Pages публикуется только после push в `main`.
